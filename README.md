# Worth the Detour

Compare a change to one day in a Markdown itinerary. Review the timing, budget, and constraints before accepting, then download the full itinerary. The built-in samples use generated or anonymized travel plans.

Run with Python 3.12. Install the dependencies from `requirements.txt`, then run `streamlit run app.py`. For Streamlit Community Cloud, use `app.py` as the entry point.

The reviewed-workflow tab displays a checked Guardians demo result. Uploaded itineraries and edits remain in the current session. Select **Try a demo** to walk through Disneyland or Los Angeles.
